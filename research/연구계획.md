# 방향성 전자기장 지도 추정을 위한 전파 표현 전이 연구계획

이 연구는 RadioMapSeer에서 학습한 전파 표현이 적은 수의 방향성 안테나 데이터로 새로운 환경의 지도를 예측하는 데 도움이 되는지 검증한다. 핵심은 전이학습과 안테나 정보를 단순히 결합하는 것이 아니라, 동일한 안테나 정보를 사용하는 scratch 모델보다 전이 모델이 얼마나 적은 학습 데이터로 같은 정확도에 도달하는지 밝히는 것이다. 제공된 선행 논문에 따라 task는 normalized EMF map prediction으로 명명한다. 절대 EMF 단위의 평가는 원본 simulator 값으로의 역변환이 확인된 경우에만 수행한다.

## 주제의 사전 타당성 검토

현재 판단은 **연구 질문은 성립하며 tensor 연결 경로도 존재하지만, 전이의 성능 이득은 아직 검증되지 않았다**이다. 입력의 의미와 좌표를 맞추는 작업을 먼저 완료하고 architecture 선택으로 넘어간다. Source와 target output이 같을 필요는 없으며 encoder 전이와 새 target decoder로 서로 다른 supervised task를 연결한다.

추가로 /home/ailab/Desktop/data/preprocessing에서 x_numeric (3072,6), x_pattern_hori와 x_pattern_vert (각 3072,360), 원래의 2채널 x_image, numeric_to_img, building_mask, y를 발견했다. index 0,1536,3071에서 원본 building 채널 0, numeric_to_img 채널 0, y는 IEIE의 대응 entry와 정확히 일치한다. 전체 파일 provenance를 확정한 것은 아니지만 target conditioning 원본의 구체적인 후보를 확보했다.

emf_project/ViT/utils/data.py의 load_data는 건물 영상의 OpenCV B/G 채널을 사용하고, field strength PNG를 grayscale로 읽어 255로 나눈다. multi-modal/utils/preprocessing.ipynb는 building 채널 0과 numeric_to_img 채널 0을 각각 x_image와 x_antenna로 저장한다. x_antenna는 Tx 점 전용 입력이 아니라 beam polygon 표현이다. multi-modal/pc_preprocessing_.ipynb의 heatmap 생성은 pattern과 antenna metadata를 이용하고 y를 계산에 사용하지 않는다. 다만 IEIE heatmap과 해당 코드 출력의 직접 재현 일치는 아직 확인하지 않았으며, shifted pattern 값을 좌표 반경으로 쓰는 방식을 물리 gain 지도와 동일시하지 않는다.

원본 배열의 첫 768개를 base로 두고 이후 entry 768+3i+j를 horizontal, vertical, combined flip으로 해석하면 선택한 base index 0,1,127,255,256,511,512,767의 building과 y가 모두 정확히 대응한다. Scalar metadata는 전체 768개에 대해 각 flip의 좌표와 azimuth 변환이 일치한다. 모든 영상 entry의 대응은 추가 검증하고, 원본 768개에서 split한 뒤 train augmentation만 사용한다.

공통 공간 입력의 후보 specification은 source [batch,2,256,256]와 target [batch,2,500,500]의 float32 tensor이며 두 채널은 검증된 building occupancy와 좌표 기반 Tx 지도다. Target 전용 입력은 scalar [batch,6], pattern [batch,2,360], 선택적 beam [batch,1,500,500]다. 각 domain output은 [batch,1,H,W]지만 label 의미와 decoder는 분리한다. Occupancy 생성 규칙은 원본 2채널 building 표현과 mask를 확인한 후 확정한다. Pattern의 +40 offset은 gain 단위 복원이 아니며 convention과 함께 명시한다.

남은 사전 검증은 건물 encoding의 정확한 의미, 좌표 x/y 및 row/column 정렬, augmentation의 전체 대응, source manifest의 원본성이다. 기존 코드에 좌표 swap 및 500−coordinate 변환이 있으므로 unit test와 시각 정합을 통해 convention을 정한다. 절대 EMF 변환식은 물리 단위 평가에 필요하지만 normalized EMF transfer 연구 자체의 필수 조건은 아니다. 이를 해결하면 encoder 선택과 학습 protocol을 확정할 수 있다.

## 연구 질문과 기여

주 연구 질문은 “공개 전파 시뮬레이션 데이터에서 학습한 공간 표현은 방향성 안테나 조건이 다른 target 환경에서 데이터 효율을 높이는가?”이다. 부 연구 질문은 안테나 조건을 별도 경로로 주입하는 방식이 단순 채널 연결보다 효과적인지, 효과가 새로운 지형과 안테나 설정에서도 유지되는지이다.

검증할 가설은 다음과 같다.

1. 같은 target 입력과 구조를 사용하는 모델에서 source pretraining이 scratch보다 낮은 오차 또는 빠른 수렴을 보인다.
2. 같은 초기화 조건에서 실제 안테나 패턴 입력은 패턴 없는 모델보다 낮은 오차를 보인다.
3. 전이의 이득은 target 학습 데이터가 적을수록 크며, 패턴 조건화 여부에 따라 달라진다. 상호작용은 네 모델의 실제 결과로 검증한다.

기여 후보는 source와 target의 물리 조건이 다른 전이 설정, target 안테나 조건화 방식, 환경 단위 분할에 기반한 데이터 효율 및 negative transfer 분석이다. 이는 결과가 뒷받침할 때 주장한다. 주파수, 안테나, 환경, label 정의가 함께 바뀌므로 현재 데이터만으로 주파수 변화의 인과 효과를 분리했다고 주장할 수 없다.

## 기존 연구와 차별점

[RadioMapSeer 데이터 논문](https://arxiv.org/abs/2212.11777)은 도시 환경의 시뮬레이션 기반 pathloss 및 RSS와 ToA 데이터를 제공한다. [RadioUNet 공식 구현](https://github.com/RonLevie/RadioUNet)은 공간 지도와 송신기 정보를 이용하는 실용적인 CNN 기준선을 제공한다. 이 연구의 source task는 ToA가 아니라 실제 보유한 gain 이미지의 정의에 맞추어 정한다.

[실내 radio map 전이학습 연구](https://doi.org/10.1109/TVT.2025.3609207)는 다른 환경으로의 adaptation과 데이터 절감을 이미 다루고 있다. [Tilt 설정 전이 연구](https://www.nokia.com/bell-labs/publications-and-media/publications/transfer-learning-for-tilt-dependent-radio-map-prediction/)도 안테나 조건 간 전이가 기존 연구 주제임을 보여준다. 따라서 “radio map에 transfer learning 적용” 자체를 신규성으로 주장하지 않는다.

2026년 9월 공개된 [BeamRMX](https://arxiv.org/abs/2609.00615)는 공간 radiation pattern과 scene geometry의 상호작용을 학습한다. 패턴 입력 자체 또는 멀티스케일 fusion 자체도 충분한 차별점이 아니다. 이 논문의 초점은 **source에서 학습한 표현을 다른 물리 조건의 target으로 가져올 때, 동일 입력 scratch 대비 얻는 데이터 효율과 실패 조건**에 둔다. 관련 연구의 전체 본문과 팀의 선행 논문을 대조한 뒤 최종 신규성을 정한다.

## OurData 선행 논문과 연구 범위

[Multi-Modal Conditioned High-Resolution Transformer for Urban Electromagnetic Field Map Prediction](https://arxiv.org/pdf/2606.27671)의 Section 3과 4.1은 3.5 GHz 시뮬레이션 EMF 지도, 500 × 500 해상도와 약 1 m/pixel을 설명한다. 기본 768개는 256개 layout과 각 3개 안테나 설정으로 구성된다. 입력에는 건물 외벽과 내부 표현, beam coverage polygon, 위치·높이·downtilt·power·azimuth의 6개 scalar, 수평·수직 360도 pattern이 있다. Output은 grayscale 기반 [0,1] normalized EMF이며 outdoor 영역에서 평가한다. FiLM과 pattern cross-attention은 이미 선행 방법이다. [해당 논문](https://arxiv.org/pdf/2606.27671)

동일 layout이 여러 split에 나타나는 기존 random split과, 새로운 layout을 평가하는 split은 다른 질문에 답한다. 논문은 train split에 4배 flip augmentation을 적용하지만, 현재 로컬 배열의 3,072개가 그 augmentation 버전인지는 확인해야 한다. 768 × 4라는 수치 관계는 단서이며 원본 sample ID를 증명하지 않는다. 선행 논문에는 물리값을 grayscale로 변환하는 정확한 식과 현재 .npy 파일별 대응이 제시되지 않아 preprocessing 확인은 여전히 필요하다. [데이터 및 한계 설명](https://arxiv.org/pdf/2606.27671)

새 논문의 방법적 기여를 FiLM이나 cross-attention의 도입으로 두지 않는다. 우선 동일 backbone과 동일 입력에서 source 초기화만 바꾸는 paired 실험으로 transfer 효과를 검증한다. Metadata와 pattern 원본을 확보하면 선행 conditioning 모델도 scratch 및 source-pretrained 두 버전으로 평가한다. CNN pilot은 작은 비용으로 가능성을 판단하는 단계이고, 최종 선행 방법 비교를 대신하지 않는다.

## 실제 데이터와 해석 조건

로컬 OurData에는 3,072개 배열 entry가 있다. 이들을 독립적인 원본 시뮬레이션 3,072회로 세지 않는다. 전체 배열을 RAM에 올리지 않고 memory mapping으로 shape과 일부 샘플을 확인했다. 아래 수치 범위는 index 0, 1536, 3071의 관찰이며 전체 extrema가 아니다.

| 파일 | Shape | dtype | 확인한 특성 | 사용 전 확인 |
| --- | --- | --- | --- | --- |
| x_image.npy | 3072 × 500 × 500 | float64 | 샘플 값 0부터 40/255까지, 41단계 | 높이 지도인지 다른 영상 표현인지 |
| x_antenna.npy | 3072 × 500 × 500 | float64 | 확인한 샘플은 0과 1 | 송신기 점인지 영역 마스크인지, 좌표와 반전 여부 |
| x_heatmap.npy | 3072 × 500 × 500 | float32 | 확인한 샘플의 최대값 약 115–117 | 안테나 prior인지 시뮬레이션 출력인지, target 의존 여부 |
| x_3ch_img.npy | 3072 × 500 × 500 × 3 | float64 | index 0에서 채널 0은 x_image, 채널 2는 x_antenna와 일치 | 채널 1의 생성과 normalization |
| y.npy | 3072 × 500 × 500 | float64 | 확인한 값은 0–1의 1/255 간격 | 물리량, 원본 단위, clipping, 전체 또는 샘플별 normalization |

파일명만으로 modality를 정의하지 않는다. 특히 x_heatmap이 y 또는 정답 시뮬레이션에서 생성된 입력이면, 이를 이용한 성능은 배포 가능한 예측 결과가 아니다. 안테나 사양과 좌표만으로 생성 가능한 prior인지 확인한 뒤 포함한다. x_3ch_img의 채널 1과 x_heatmap도 동일하다고 가정하지 않는다.

Target 주파수와 방향성 설정은 위 선행 논문의 데이터 설명을 근거로 사용한다. 로컬 파일의 버전과 설정 대응은 원본 manifest로 검증한다. y가 단순 colormap의 grayscale 변환이라면 원본 물리량 복원이 불가능할 수 있다. 샘플별 min-max이면 절대 크기 정보가 없어져 노출량 및 절대 EMF 예측 주장을 제한한다. 8-bit 양자화는 데이터 표현 특성이지 성능 결과가 아니다.

RadioMapSeer 로컬 폴더에는 혼합된 파일 구조가 있다. DPM, IRT2, carsDPM, carsIRT2는 각각 56,080개 파일이며, IRT4와 carsIRT4는 각각 1,402개이다. 원본 공개 설명의 700 maps × 80 Tx와 로컬 개수가 달라 추가 map 또는 파일을 검증해야 한다. gain/gt는 3,072개이고 pattern 및 heatmap 등에도 3,072개 PNG가 있다. **숫자가 일치한다는 이유만으로 target과 동일하다고 단정할 수는 없지만**, source 전용 파일로 취급하기 전에 provenance를 확인해야 한다.

Source 후보는 buildings_complete_orig, antennas_orig, DPM 또는 IRT2와 antenna JSON이다. 첫 source PNG들은 256 × 256이고 OurData는 500 × 500이다. 현재 buildings_complete의 0.png도 256 × 256이므로 파일명 suffix만으로 원본 여부를 판단하지 않는다. 정합한 건물 지도, Tx, gain 쌍을 명시적 manifest로 고정한다. PNG 변환 스크립트에는 antenna transpose가 있으므로 공간 좌표 정렬을 검증한다. 이 스크립트를 실행하지 않는다.

## 데이터 분할과 누수 방지

무작위 샘플 분할보다 지형 단위 분할이 우선이다. 동일 지형의 여러 Tx나 안테나 설정이 train과 test에 나뉘면 새로운 환경에 대한 성능을 과대평가할 수 있다. 원본 scene ID를 확보하고, 회전 및 반사 augmentation은 split 이후 train에서만 생성한다.

전체 3,072개 x_image를 검사한 결과 회전 동등 그룹은 172개다. 168개 그룹은 각각 18개 샘플이고, 4개 그룹은 각각 12개 샘플이다. 이는 반복 영상 표현이 존재함을 보여주며 단순 entry 무작위 분할을 피해야 할 근거다. 172는 회전 동등 영상 그룹 수이며 논문의 256개 layout이나 독립 물리 환경 수와 동일한 개념이 아니다.

geometry_groups.json은 x_image를 8-bit로 환산한 뒤 0, 90, 180, 270도 회전 중 동일한 지도를 묶는 보조 자료다. 이 그룹은 물리적인 scene ID를 대체하지 않는다. 반사, crop, 약간 다른 높이 표현, 동일 도시의 겹치는 타일 등도 별도로 검토해야 한다.

저장된 augmentation이라면 원본 sample ID를 먼저 복원하고 모든 변형을 같은 split에 둔다. 이 관계가 확인되기 전에는 3,072개 entry로 seed=42 random split을 재현하지 않는다. 선행 split의 재현 실험과 새로운 layout split의 주 실험을 분리하고, 다른 split의 오차를 직접 비교하지 않는다.

지형 그룹이 충분하면 약 70/15/15 비율로 train/validation/test 그룹을 고정한다. 그룹 수가 작으면 leave-one-environment-out 평가를 사용하고, 모든 fold에서 validation 환경을 분리한다. 하나의 지형만 있으면 unseen topology 주장을 제외하고 unseen Tx 또는 antenna setting으로 연구 범위를 좁힌다. Source와 target이 동일 지도에서 유래했는지도 검사한다. Target test 지형이 source pretraining에 존재하면 topology 일반화와 분리해 보고한다.

Source도 map ID 단위로 train/validation/test를 분리하고 하나의 simulator 종류를 주 실험에 사용한다. Source manifest에는 dataset domain, simulator, map ID, Tx ID, 파일 경로와 spatial alignment를 기록한다. Target manifest에는 scene ID, Tx 위치, 방향, tilt, 안테나 종류, 출력 단위와 원본 생성 run ID를 기록한다.

## 입력과 출력의 정합

공통 encoder의 pilot 입력은 검증된 건물 occupancy B와 Tx 위치 지도 T의 두 채널로 통일한다. Target의 기존 채널을 높이 지도라고 단정하지 않는다. 건물 외벽 및 내부 encoding과 beam polygon의 로컬 대응을 확인하고, beam 정보를 건물 입력과 분리한다. x_antenna가 송신기 점이 아니라면 원본 좌표에서 T를 새로 만든다. Source와 target의 building 표현은 서로 의미가 같도록 occupancy 또는 검증된 높이로 변환한다. 높이를 실제 단위로 복원할 수 없다면 occupancy 공통 입력과 target 높이 입력을 별도 ablation으로 다룬다.

안테나 입력 Q는 radiation pattern의 각도별 gain 또는 좌표계가 맞는 spatial pattern prior다. Tx와 pixel 좌표가 있으면 상대 거리와 방향도 만들 수 있다. 다만 meter per pixel, 높이, azimuth, tilt, pattern convention이 확보된 경우에만 물리 단위를 사용한다. 선행 방법에 필요한 scalar와 각도별 pattern은 이번에 확인한 OurData의 5개 .npy만으로 모두 확보됐다고 볼 수 없다. 원본 metadata와 pattern 파일을 확보한 뒤 해당 경로를 구현한다.

첫 구현은 fully convolutional U-Net으로 한다. Source 256 × 256, target 500 × 500을 원래 해상도로 처리하고 downsampling에 필요한 크기로 padding한 뒤 crop한다. 안테나 점과 마스크에는 nearest interpolation을 쓰며 지도 label의 resize를 최소화한다. 숫자 크기를 맞추려고 target을 256 × 256으로 바꾸는 실험은 원본 해상도 결과와 구분한다. 해상도가 같아도 공간적 범위가 같다는 뜻은 아니다.

Source output과 target output의 단위가 다르면 shared encoder만 전이하고 target decoder와 output head는 새로 초기화한다. Source normalized gain과 target normalized EMF를 같은 label로 간주하지 않는다. Input 및 output scaling은 학습 split에서만 정하고 validation/test에 고정한다.

## 모델 설계

가장 작은 방법은 공간 encoder E(B,T), 안테나 encoder P(Q), target decoder D로 구성한다. Source에서는 E와 source decoder로 gain map을 학습한다. Target에서는 E를 가져오고 P 및 target decoder를 새로 학습한다. CNN backbone을 먼저 쓰면 transfer와 conditioning 효과를 구조 선택과 분리하기 쉽다.

안테나 입력이 공간 지도이면 별도 CNN의 feature를 공간 encoder와 같은 scale에서 연결하고 1 × 1 convolution으로 융합한다. 각도별 pattern이나 scalar이면 작은 encoder로 condition vector를 만들고 FiLM의 scale 및 bias로 공간 feature를 조정한다. 두 종류의 입력이 있다는 증거 없이 양쪽을 동시에 구현하지 않는다. 초기에는 하나의 bottleneck fusion으로 시작하고 multiscale fusion은 후속 비교로 둔다.

권장 계산 구조는 다음과 같다.

```text
Source: [B, T] → spatial encoder → source decoder → gain
                              ↓ encoder weights
Target: [B, T] → spatial encoder ─┐
                                 ├→ fusion → new target decoder → target map
        verified pattern → encoder ┘
```

공간 pattern을 곱하기만 하면 반사 및 회절 경로를 설명하지 못할 수 있다. 그러므로 자유공간 baseline이나 pattern × spatial prediction을 단순 기준선으로 평가할 수 있지만, 이를 물리적으로 정확한 decomposition이라고 전제하지 않는다. 물리 loss를 쓰지 않는 conditioning 모델에는 “physics-informed”보다 “antenna-conditioned”라는 표현이 정확하다.

## 핵심 비교 실험

| 모델 | 초기화 | Target 입력 | 목적 |
| --- | --- | --- | --- |
| A | Scratch | B와 T | 공간 기준선 |
| B | Scratch | B와 T 및 Q | 안테나 입력의 효과 |
| C | RadioMapSeer encoder | B와 T | 패턴 없는 전이 효과 |
| D | RadioMapSeer encoder | B와 T 및 Q | 제안 설정 |
| E | Scratch | B와 T 및 Q를 early concatenation | 별도 fusion의 필요성 |
| F | RadioMapSeer encoder | 동일 입력의 early concatenation | 전이와 fusion 구조의 구분 |

논문의 중심 비교는 D 대 B다. D 대 C의 개선은 안테나 정보의 유용성을 보여주지만, 전이 자체의 이득을 입증하지 않는다. A와 C, B와 D는 각각 같은 구조와 같은 입력을 사용한다. Pattern 없는 모델은 입력 정보가 적으므로 배포 후보라기보다 modality ablation이다. E/F를 추가하면 입력 추가와 fusion 설계의 효과를 구분할 수 있다. Parameter 수와 FLOPs도 보고한다.

오차를 eA, eB, eC, eD라 두면 패턴 없는 전이 이득은 eA−eC, 패턴 있는 전이 이득은 eB−eD다. 상호작용은 (eB−eD)−(eA−eC)로 정의한다. 양수이면 패턴 조건에서 transfer 이득이 더 크다. D가 가장 좋다는 사실만으로 synergy를 주장하지 않는다.

Target train 예산은 전체 train 데이터의 10%, 25%, 50%, 100%로 시작한다. 그룹 수가 충분할 때 5%를 추가한다. 같은 seed와 같은 subset을 모든 모델에 사용하고 subset을 중첩한다. Target train 지형을 유지하며 설정 수만 줄이는 실험과 train 지형 수 자체를 줄이는 실험은 별개로 보고한다. 그룹 수가 적다면 실현 가능한 예산으로 조정한다.

처음에는 A–D를 25%와 100% 예산에서 3개 seed로 평가하고, source pretraining도 우선 1개 seed의 pilot을 수행한다. 이 단계는 가능성 판단용이다. 본 실험에서는 target subset 및 최적화 seed를 5개 사용하고, source seed 민감도도 추가 확인한다. 초기화 비교는 동일 validation 탐색 예산을 부여하되 각 모델의 적절한 learning rate를 validation에서 선택한다. Encoder warm-up 후 전체 fine-tuning을 기본으로 하고 frozen encoder는 별도 ablation으로 둔다.

## 학습과 평가

첫 loss는 유효 영역의 MAE 또는 Huber 하나로 시작한다. Building 내부, nodata와 영값의 의미를 원본 metadata로 구분하고, y=0을 임의로 invalid 처리하지 않는다. SSIM loss, gradient loss, physical prior를 처음부터 추가하면 transfer 효과 해석이 어려워진다.

주 지표는 샘플별 유효 영역 MAE와 RMSE를 계산한 후 scene별로 평균한 값이다. 샘플이 많은 지형이 결과를 지배하지 않도록 scene macro average를 함께 보고한다. 물리값으로 복원 가능하면 V/m 또는 정의된 log 단위의 오차를 주 지표로 사용하고, 불가능하면 normalized image error로 명시한다. SSIM은 보조 지표이며 physical correctness를 대신하지 않는다. NMSE는 reference energy와 계산 convention을 명시한다.

고강도 영역의 오차는 ground truth 상위 분위수 영역에서 부 지표로 분석할 수 있다. 실제 노출 기준 threshold 결과는 절대 EMF 단위가 확인된 경우에만 계산한다. 방향, Tx 거리, LOS/NLOS별 분석도 원본 조건 또는 검증된 기하학 규칙이 있을 때 수행한다.

Test 결과는 paired 비교를 사용하고 scene를 독립 단위로 bootstrap한다. Pixel 수를 독립 샘플 수로 취급하지 않는다. Seed 간 변동과 scene 간 변동은 별도로 표시한다. Scene 수가 적으면 bootstrap CI의 한계를 설명하고 fold별 결과를 공개한다. 최소 유의미 개선폭은 단위와 데이터 정밀도가 확인된 후 test를 보기 전에 정한다.

Data efficiency는 동일 목표 오차에 도달하는 target train 샘플 또는 지형 수로 비교한다. 공통 도달 구간에서만 절감률을 계산하고 미도달 예산 밖으로 extrapolation하지 않는다. Source pretraining 비용을 포함한 전체 GPU 시간과 adaptation 시간, inference latency를 따로 보고한다. Scratch의 충분히 긴 학습 결과도 포함해 단순 convergence 속도 차이와 최종 정확도 차이를 구분한다.

## 추가 검증과 실패 해석

주 결과가 성립하면 frozen 대 full fine-tuning, source DPM 대 IRT2, early concatenation 대 별도 fusion을 비교한다. 가능하면 동일 backbone의 일반 이미지 pretraining 또는 구조 재구성 pretraining을 추가해 propagation supervision의 기여를 검증한다. 호환되지 않는 backbone을 무리하게 맞추지 않는다.

Pattern을 permutation하거나 상수 입력으로 치환하는 평가는 모델이 안테나 조건을 실제 사용하는지 보는 진단이다. 단독으로 인과 관계를 증명하지 않으며, 배포 분포와 다른 입력일 수 있음을 해석에 반영한다. Target test 조건의 패턴을 학습에 누출시키지 않는다.

D가 B보다 좋고 CI와 예산 곡선이 이를 뒷받침하면 transfer의 유용성을 주장할 수 있다. D와 B가 비슷하면 pattern 정보의 효과는 있더라도 source transfer의 기여는 작다. D가 B보다 나쁘면 negative transfer를 보고하고 source–target 차이, layer별 전이 및 freeze 범위를 분석한다. D가 C보다 좋다는 이유만으로 negative transfer가 해결됐다고 결론 내리지 않는다.

## 논문 구성과 산출물

가제는 “Data Efficient Transfer of Radio Propagation Representations for Antenna Conditioned EMF Map Estimation”이다. 결과는 normalized EMF 단위로 보고하고 절대 노출량 예측과 구분한다.

Introduction은 방향성 조건의 지도 생성 비용과 target 데이터 부족에서 시작한다. Related work는 radio map prediction, 환경 및 안테나 조건 전이, pattern conditioning으로 나눈다. Problem formulation은 source/target의 입력, label 단위와 domain gap을 정의한다. Method는 shared spatial encoder와 target conditioning만 설명하고, Experiments에서 분할, 예산과 paired 비교를 제시한다. Discussion은 negative transfer와 물리 단위 복원 한계를 포함한다.

핵심 figure는 데이터 및 domain 비교, 학습 구조, target 예산별 오차 곡선, 같은 test scene의 정답과 A–D prediction 및 error map이다. 표는 데이터 metadata, 전체 예산 A–D 결과, 동일 입력 B–D의 예산별 결과, fusion 및 encoder ablation으로 구성한다. 실제 결과 전에는 수치가 있는 abstract나 결과 결론을 작성하지 않는다.

## 실행 순서

1. 원본 생성 및 전처리 코드에서 label 단위, x_heatmap 및 채널 1의 생성, 안테나 mask, 지형 ID와 공간 좌표를 확인한다.
2. Source와 target manifest를 분리하고 중복 지형, transpose 및 pattern alignment를 검증한다.
3. 검증된 B와 T로 scratch baseline을 학습한다. Pattern의 배포 가능성이 확인되면 B 모델을 추가한다.
4. 동일 공간 backbone의 source encoder를 학습하고 C/D에 전이한다.
5. 25%와 100% pilot 이후 전체 예산 및 반복 실험을 진행한다.
6. 동일 입력 D–B의 결과를 중심으로 contribution과 논문 제목을 확정한다.

현재 산출물은 데이터에 맞춘 연구 및 실험 설계다. 모델 학습이나 성능 검증 결과는 아직 없다. 원래 실험주제.md는 보존한다.
