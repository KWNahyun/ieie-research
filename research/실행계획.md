# 전파 표현 전이 연구 실행계획

작성일: 2026-10-08. 연구 질문과 해석 원칙은 [연구계획.md](연구계획.md)를 따른다. 이 문서는 해당 질문을 실제 데이터 검증, 구현, 실험으로 옮기는 작업 순서다. 일정은 GPU 가용성과 검증 결과에 따라 조정하는 작업량 추정이며 실험 결과가 아니다.

## 전체 감사 후 적용할 변경 사항

2026-10-08 전체 감사 결과는 [data_audit.md](data_audit.md)와 [data_contract.json](data_contract.json)에 기록했다. 아래 초안보다 이 변경 사항을 우선 적용한다.

- 768개 base의 원본 대응은 모두 검증됐다. Excel의 256행은 configuration이며 building ID와 D4 geometry는 86개다. Provisional split은 60/12/14 group, 534/108/126 base sample이다.
- 초기 train/validation/test는 모두 base-only로 한다. 저장된 flip은 영상·numeric 대응은 맞지만 비대칭 horizontal pattern을 그대로 반복하므로 물리적 증강으로 아직 검증되지 않았다.
- building_mask는 모든 entry에서 y>0과 동일하고 동일 building에서도 setting에 따라 달라진다. Occupancy 입력이나 독립 outdoor mask로 승인하지 않는다.
- Beam은 모든 entry가 legacy code에서 재생성되지만 transpose marker 문제를 확인했다. Core pilot에서는 제외한다.
- 데이터 검증 gate는 아직 전부 통과하지 않았다. 독립 footprint/outdoor mask와 지리 중복을 해결하거나, 이를 반영해 연구 범위와 평가 protocol을 확정한 후 학습한다.

### 원본 geometry 부재 확인 후 empirical pilot 경로

사용자는 original building 파일과 PNG rendering 코드가 존재하지 않는다고 확인했다. 따라서 그 자료의 확보를 pilot 필수 조건으로 두지 않고 다음 범위로 진행한다. 이 수정은 위의 gate 대기와 occupancy 미승인 사항을 pilot에 한해 대체한다.

- Target 공간 채널 B는 **image geometry proxy**로 명명한다. Raw input PNG의 B/G가 모두 정확히 0인 pixel을 1로 한다. Label-dependent mask나 label에 맞춘 threshold는 사용하지 않는다. Source B는 binary building PNG의 nonzero pixel이다. 두 domain의 renderer 차이는 잔여 domain gap이다.
- 주 loss와 지표는 full-raster normalized MAE/RMSE이며 image geometry group의 macro average를 사용한다. Outdoor-only 또는 독립 physical scene 일반화로 명명하지 않는다. 기존 label-positive mask 평가는 명시적인 보조 재현으로만 가능하다.
- A/B는 같은 두 공간 채널 B/T와 같은 encoder/decoder 초기화를 사용한다. B만 7개 scalar feature와 2×360 pattern의 bottleneck FiLM을 추가한다. Azimuth의 sin/cos 변환으로 scalar feature가 원본 6개에서 7개가 된다.
- Scratch A/B 구현과 작은 CPU smoke를 먼저 수행한다. Smoke는 2개 train/2개 validation sample의 8 updates이며 성능 비교에 사용하지 않는다. Full 25/100% pilot은 compute 설정과 동일 validation 탐색 예산을 확정해 별도로 수행한다.
- Rendering fidelity, geographic tile overlap 및 source-target overlap은 한계로 유지한다. 저장된 augmentation은 계속 비활성화한다.

## 1. 목표와 주 비교

목표는 RadioMapSeer에서 학습한 공간 encoder가 방향성 안테나 조건의 normalized EMF 예측에서 target 데이터 요구량을 줄이는지 검증하는 것이다. 주 비교는 **동일한 건물·Tx·scalar·pattern 입력과 구조를 쓰는 scratch B와 pretrained D**다. 출력의 절대 단위가 복원되지 않아도 normalized EMF 연구는 진행한다.

진행 순서는 데이터 검증 → 고정 split → scratch 구현 → source pretraining → paired pilot → 본 실험이다. 데이터 검증 실패를 모델 성능으로 보완하지 않는다. 안테나 조건을 검증하지 못하면 A/C 공간 전이 실험부터 진행하고 B/D는 보류한다.

## 3. 단계 1 — 데이터 계약 확정 (예상 3–5 작업일)

1. 생성·전처리 코드에서 numeric 6개 열과 pattern의 의미를 찾아 `data_contract.json`에 근거 파일·위치와 함께 기록한다. 기존 연구계획의 설명은 검증 가설로 취급한다.

3. Tx의 x/y와 image row/column을 확정한다. 연속 좌표의 반사와 정수 pixel 반사는 분리하고 `500-coordinate`와 `499-index`의 사용 근거를 확인한다. 경계 좌표, 비대칭 건물, 알려진 azimuth에 대한 검증 및 overlay를 만든다.

6. Source의 building/Tx/gain을 map ID와 Tx ID로 연결하고 DPM 하나를 첫 simulator 후보로 둔다. 파일 개수 차이, 원본 map 범위, transpose와 target 지도 중복을 확인한다. 검증한 파일만 manifest에 포함한다.

## 4. 단계 2 — 누수 없는 split과 데이터 예산 (예상 1–2 작업일)

Target manifest의 최소 필드는 entry index, base sample ID, transform, scene ID 또는 보수적 geometry group ID, antenna setting ID, modality 경로와 좌표 convention이다. 물리 scene ID를 복원하지 못하면 geometry 기반 평가라고 보고하고 독립 scene 일반화로 표현하지 않는다.

원본 scene를 기준으로 약 70/15/15 train/validation/test를 만든다. 동일 scene의 설정과 변형은 한 split에 묶는다. 기존 geometry_groups.json의 회전 그룹에 반사·겹치는 tile 가능성을 추가 검사하고, 의심되는 관계는 같은 그룹으로 묶는다. 그룹 split의 실제 sample 수와 조건 분포를 공개한다. Source도 map 단위로 분할한다.

Target test 지도와 source 지도에 중복이 확인되면 해당 source map을 pretraining에서 제외하거나, 겹침이 없는 평가와 별도로 보고한다. 모든 모델에 동일 split을 쓰고 test는 본 실험 protocol을 확정한 뒤 평가한다. Pilot 선택은 validation 결과를 사용한다.

Target train 예산은 10/25/50/100%를 기본으로 한다. 첫 pilot은 25/100%만 수행한다. Augmentation entry가 아닌 base sample 수와 지형 수를 센다. 각 seed의 subset은 중첩하며 B/D를 포함한 모든 비교 모델이 동일 subset을 사용한다.

두 예산 축은 분리한다: (a) 가능한 범위에서 train 지형을 유지하며 설정 수를 감소, (b) train 지형 수를 감소. 모든 지형에 하나씩 할당할 수 없는 작은 예산은 (a)로 부르지 않는다. 기본 주 실험은 (b)로 두고 (a)는 가능한 예산에서 보조 비교한다.

산출물: `splits/target_groups.json`, `splits/source_maps.json`, seed별 subset ID 목록, split 간 그룹·base ID 교집합이 없는 검증 결과.

## 5. 단계 3 — 최소 모델과 학습 경로 (예상 3–5 작업일)

공간 입력은 검증된 occupancy B와 좌표 기반 Tx 지도 T 두 채널이다. Fully convolutional U-Net의 encoder를 source와 target에 공유 가능한 구조로 구현한다. Source는 256×256, target은 500×500이며 필요한 배수로 padding하고 출력은 원래 크기로 crop한다. Target decoder와 head는 항상 새로 초기화한다.

첫 conditioning은 scalar MLP와 수평·수직 pattern encoder가 만든 vector를 bottleneck FiLM으로 주입한다. Scalar의 azimuth는 convention 확인 후 sin/cos로 표현한다. Pattern은 두 채널의 1D 입력으로 사용하고 단위 복원 없이도 관측 convention을 명시한다. Scalar/pattern 정규화 통계는 train에서만 계산한다. Beam polygon과 heatmap은 주 입력에서 제외하고, 생성 근거를 확인한 뒤 별도 ablation으로 추가한다.

| 모델 | 초기화 | Target 입력 | 비교 목적 |
| --- | --- | --- | --- |
| A | scratch | B,T | 공간 기준선 |
| B | scratch | B,T,검증된 scalar와 pattern | conditioning 기준선 |
| C | source encoder | B,T | 공간 전이 효과 |
| D | source encoder | B,T,검증된 scalar와 pattern | 동일 입력 B 대비 전이 효과 |

B/D는 동일 구조·입력·decoder 초기화 seed를 사용하고 encoder 초기화만 다르게 한다. A/C도 같은 원칙을 따른다. Scalar와 pattern을 함께 넣은 B−A 차이는 전체 conditioning 효과다. Pattern만의 기여는 scalar-only 모델을 추가해 분리한다.

초기 loss는 검증된 유효 영역 MAE다. AdamW와 learning rate 후보 1e-4,3e-4,1e-3를 pilot validation에서 같은 탐색 예산으로 비교한다. Encoder의 낮은 learning rate와 짧은 warm-up은 pretrained 후보 설정으로 검증하고 선택 근거를 기록한다. 최대 update 수, early stopping, validation 주기와 batch 크기는 처리량 smoke run 후 고정한다. 모델별 최적 LR는 같을 필요가 없지만 탐색 예산은 같게 한다.

검증 항목은 작은 batch의 forward/backward, 500×500 crop 복원, 유효 mask의 loss 반영, checkpoint encoder 적재, train 통계의 validation 적용이다. 소수 train sample에서 loss가 감소하는지 확인하되 이를 일반화 결과로 해석하지 않는다.

## 6. 단계 4 — pilot과 진행 판단 (예상 1–2주, GPU에 따라 변동)

Source pretraining은 우선 1개 seed로 진행하고 source validation에서 checkpoint를 선택한다. Source는 target test 결과로 선택하지 않는다. A–D × 2개 target 예산 × 3개 seed로 총 24회 target 학습을 수행한다. Validation 탐색과 smoke run은 이 24회에 별도로 기록한다.

Pilot에서 확인할 것은 B/D paired validation 오차, 충분한 학습 후 수렴, seed 변동, conditioning의 사용 여부, 메모리·시간이다. 개선폭 기준은 pilot validation과 label 정밀도를 참고해 본 test를 보기 전에 숫자로 확정한다.

- D가 B보다 안정적으로 개선되면 예산 곡선 본 실험으로 진행한다.
- 차이가 작으면 LR, source 품질, 입력 정합과 encoder 전이 범위를 제한된 validation 실험으로 점검한다. 반복 탐색의 상한을 사전에 정한다.
- D가 B보다 나쁘면 negative transfer를 보존하고 layer별 전이 또는 frozen/full fine-tuning 비교를 진행한다. 좋은 결과만 남기지 않는다.
- A/C는 가능하지만 conditioning 검증이 끝나지 않으면 공간 전이 결과로 범위를 좁힌다.

Pilot 종료 산출물: validation 결과표, 실행 시간과 peak VRAM, 선택한 설정, 본 실험 protocol 및 진행 판단 기록.

## 7. 단계 5 — 본 실험과 분석 (예상 2–3주 이상)

A–D × 4개 예산 × 5개 seed로 기본 80회 target 학습을 수행한다. Pilot 설정을 고정하고 선택된 source 조건에서 추가 pretraining seed 2개를 만들어 B/D의 25%와 100% 비교로 source 초기화 민감도를 평가한다. Source seed와 target subset/최적화 seed를 구분해 기록한다.

주 지표는 outdoor 또는 검증된 유효 영역의 normalized MAE, 보조 지표는 RMSE와 SSIM이다. 샘플 오차를 먼저 계산하고 scene별 평균 후 scene macro average를 보고한다. Physical scene ID가 없으면 geometry-group macro average로 명명한다. Bootstrap 단위는 scene 또는 명시한 group이며 pixel을 독립 표본으로 사용하지 않는다.

동일 test scene에서 B−D paired 차이와 95% bootstrap CI를 계산하고 seed별 변동을 별도로 표시한다. Transfer interaction은 `(eB−eD)−(eA−eC)`로 보고한다. 데이터 절감률은 공통 도달 오차 구간에서 계산하고 관측 예산 밖으로 외삽하지 않는다.

Scratch를 충분히 오래 학습한 비교를 포함하고 source pretraining 시간, target adaptation 시간, 전체 GPU 시간과 inference latency를 분리한다. 최종 성능과 빠른 수렴을 각각 설명한다.

주 실험 이후 우선순위: scalar-only conditioning → early fusion의 동일 초기화 비교 → frozen/full encoder → source DPM/IRT2 → 선행 conditioning backbone의 scratch/pretrained 비교. 각 ablation은 질문 하나에 답하도록 설계하고 모든 조합을 무조건 실행하지 않는다. 선행 방법 구현 및 관련 논문 본문 대조는 최종 신규성 주장 전에 완료한다.

## 8. 재현성과 최종 산출물

실험별 config, source checkpoint ID, split/subset ID, code revision, seed, train 통계, 선택한 epoch/update, valid pixel 수, runtime와 실패 이유를 저장한다. Prediction은 대표 test scene뿐 아니라 전체 scene별 metric도 보존한다. 원본 대용량 배열 복사 없이 경로와 파일 크기·수정 시각을 기록하고 필요한 경우 순차 hash를 추가한다.

최종 산출물은 데이터 계약과 manifest, 누수 검증된 split, 학습·평가 코드, 재현 가능한 checkpoint, B/D 예산 곡선과 paired 결과, A–D 예측 및 error map, negative transfer 분석이다. 절대 EMF 역변환이 입증되지 않으면 모든 결과의 단위는 normalized EMF로 유지한다.

가장 먼저 실행할 작업은 전체 augmentation 대응 검사와 scalar/pattern 좌표 계약 확정이다. 이 두 작업이 완료되면 건물 occupancy·Tx·평가 mask를 확정하고 scratch A/B 학습으로 넘어간다.

### 2026-10-10 — 자율 실행 후속 단계

사용자가 약10시간 추가 확인 없는 실험 진행을 승인했다. [Source sensitivity protocol](source_sensitivity_protocol.md)에 따라4개 source/24개 target fit를 GPU2에서 진행한다. 이후 [Main protocol](main_protocol.md)에 고정한 B/D ×4budget ×5target seed, D의3source seed를 실행한다. 전체80 fit 중24개를 검증 후 재사용하며56개가 새 실행이다. Source 민감도 검증 완료를 gate로 기다리고, 본실험80개 checkpoint 검증과 manifest 고정 후 test를 평가한다. Bootstrap은14개 image geometry group 단위이며 물리/geographic 일반화 주장은 하지 않는다. 상세 상태와 결과는 각 runs 디렉터리에 저장한다.

### 2026-10-11 — 자율 실험 완료 및 독립 감사

Source 민감도28단계, main80개 fit/test, spatial A/C40개 fit/test가2026-10-10 승인된10시간 안에 완료됐다. Main D/B test MAE 감소는10/25/50/100%에서2.69/3.71/2.97/2.20%다. Source5개/target30개 검증 및 main80/A-C40개 독립 감사가 통과했다. 최종 model은 epoch cap이 없으며4개 capped 원본을 보존했다. Optional crossed grid는 시간 한도 이후 신규 stage0개로 종료했다. 전체 결과·비용·한계와 후속 연구는 [최종 보고서](autonomous_20261010_report.md)를 따른다. Raw data와 고정된 학습 코드/contract/splits는 변경하지 않았다.
